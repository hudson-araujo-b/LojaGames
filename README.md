# Loja Games

## [LojaGames](https://hudson-araujo-b.github.io/LojaGames/)

Projeto de uma loja de jogos desenvolvido com HTML, CSS e JavaScript.

---

## Objetivo

O principal objetivo deste projeto foi compreender o fluxo de desenvolvimento de aplicações em ambientes colaborativos, utilizando práticas comuns do mercado como:

- **Forks**
- **Merges**
- **Branches**
- **Pull Requests**
- **Code Reviews**
